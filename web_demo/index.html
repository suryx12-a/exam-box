VIVA PROTOTYPE SECURITY & PRIVACY ARCHITECTURE

• Privacy-First Telemetry: Only audit metadata and sensor telemetry are transmitted. PINs, biometric scans, and confidential examination question papers are strictly stored inside Android Keystore and never sent across the network.
• Local Network Link: Prototype HTTP communication without TLS is deployed for isolated lab demonstration on 192.168.1.39. In production, HTTPS with certificate pinning and mutual TLS (mTLS) is mandatory.
• Platform Disclosures: System monitors application-level security events and Android OS sensor reports; does not claim raw biometric verification beyond BiometricPrompt or OS lock detection without enterprise MDM profiles.
